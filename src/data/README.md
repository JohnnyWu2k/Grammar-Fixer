# 校正資料

本目錄詞表由本專案編寫，使用儲存庫的 MIT 授權，沒有引入第三方語料或詞庫。

- `english.ts`：常用英文與開發用語、常見誤拼對照。刪除索引僅產生候選，未知字不等同錯字。
- `chinese.ts`：中文詞組用字對照，僅提供待確認建議。
- `zhuyin.ts`：繁體中文常用詞及標準注音。格式為 `文字|空格分隔的音節|相對權重`。

權重是人工排序值，不是語料統計。第一聲不加符號；輕聲 `˙` 置於音節後供解析。
字數與音節數一致的詞組也會產生單字候選，搭配 Trie、動態規劃與有界 beam search 組合。
輸入中省略的聲調會降低分數，明確輸入的聲調則保留約束。
